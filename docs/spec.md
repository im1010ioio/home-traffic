# 竹東往台北轉乘攻略規格

## 目標

提供家庭成員一個手機優先的固定路線看板，整合當日低班次、多段轉乘資訊，快速判斷下一組可搭行程。

## 主看板

依序提供「國光客運」「台鐵」「高鐵」三個分頁。每頁預設顯示最近三組，並可展開今日全部；行程依第一段發車時間排序，同時發車時以轉乘較少者優先。

每張卡片顯示剩餘時間、各段起訖站、發車與抵達時間、車次、轉乘站、等待時間、最終抵達時間及總時數。榮華直達新竹的班次標示「直達新竹」。

## 時間規則

- 出發準備：榮華 25 分鐘、朝陽路 15 分鐘。
- 最短轉乘：竹中 8 分鐘、六家步行至高鐵新竹 10 分鐘、新竹站內 10 分鐘。
- 主看板及班次查詢只處理今天。

## 各段班表

只提供新竹至台北的台鐵與高鐵班次，不讀取或呈現 5608、9003 資料。

「僅顯示對號列車」只套用新竹至台北的台鐵路段，在主看板與各段班表共用裝置偏好，預設開啟。

## 資料與安全

GitHub Actions 每日台灣時間 04:30 使用 Secrets 中的 TDX Client ID／Secret 取得資料，產生不含憑證的 JSON 並提交儲存庫。網頁不直接呼叫 TDX。手動更新由有寫入權限者在 Actions 執行，每日最多兩次且不可並行。

資料過期或離線時保留舊班表並顯示醒目警語、資料日期與最後更新時間；舊資料停用即時倒數。頁尾標示 TDX 資料來源及以官方營運資訊為準。

## 發布

以 Vite、TypeScript 與原生 HTML/CSS 建置 GitHub Pages。網站公開、不含個人資料，支援深色模式、PWA 安裝及最後班表離線存取。
