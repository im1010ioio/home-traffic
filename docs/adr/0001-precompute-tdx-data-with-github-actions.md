# 使用 GitHub Actions 預先產生 TDX 當日資料

網站部署於只能提供靜態內容的 GitHub Pages。為避免在瀏覽器暴露 TDX Client Secret，並節省基礎會員額度，由 GitHub Actions 安全讀取 Secrets、每日預先取得並整理當日班表，再將不含憑證的資料發布至 GitHub Pages；第一版不由網頁直接呼叫 TDX，也不自行擷取公車即時資訊。每日產生的班表 JSON 會提交至儲存庫，保留資料版本並形成實質的儲存庫活動。

## Consequences

網頁開啟時讀取預先產生的資料，不保證反映開啟當下才發生的班表異動。公車即時動態改由官方即時資訊連結提供。工作流程同時支援手動執行；網頁必須顯示資料更新時間，且當資料日期不是今天時提出明顯警告，以便發現排程延遲或遭 GitHub 停用。

每日排程於 `Asia/Taipei` 04:30 執行，避開整點常見壅塞並在早晨出門前完成資料更新。

GitHub Pages 的手動更新按鈕只連往 GitHub Actions 工作流程頁面，不在瀏覽器保存或使用具寫入權限的 GitHub 憑證。手動執行限具有儲存庫寫入權限者，每日最多兩次，且更新工作不可並行；超過限制時不得呼叫 TDX。
